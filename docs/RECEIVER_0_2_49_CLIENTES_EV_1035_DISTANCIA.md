# Receiver 0.2.49 (versionCode 50) — viajes y kilometraje eléctrico

## Cambios autorizados por el propietario (12/11/2026)
1. **Botones Jornada y Cliente:** cuando un viaje ya está iniciado el botón INICIAR queda deshabilitado y visiblemente gris; con pausa pasa a REANUDAR y se habilita solo al estar pausado. PAUSAR y TERMINAR solo se habilitan en estados válidos, y se deshabilita pausar o cerrar Jornada mientras haya cliente sin cerrar (la jornada pide finalizar cliente primero).
2. **Kilómetros con térmico apagado:** se clasifican únicamente intervalos positivos de distancia usando RPM de la clave OEM **1035** (0 = térmico apagado, >0 = prendido, lectura fallida = desconocido). Para cada jornada se guardan `ev_distance_km`, `ice_distance_km`, `unknown_distance_km`; para cada cliente se guardan los correspondientes contadores persistentes y se excluyen pausas manuales de cliente. El Cockpit muestra **KM MOTOR APAGADO · 1035** en la primera pantalla. El historial nuevo conserva el desglose en `client_drive_km.csv`, vinculado al ID del cliente. Histórico anterior: EV km desconocido, no cero inventado.
3. **Sync de cliente al terminar:** `T1JourneyStore.finish()` agrega la fila en `client_trips.csv` como antes, agrega el desglose al sidecar local, crea un **informe de evento CLIENT_FINISHED_V1** en formato `code_diag_YYYYMMDD_HHMMSS.csv` con ID de cliente, inicio, fin, trip IDs, kilómetros, reparto 1035, eventos de 500m, energía, costo nafta, factor de ajuste. Nunca envía nombre de pasajero, etiqueta, GPS, VIN ni CSV crudo. Usa el **QR y Edge Function existentes**, firma privada y checksum/idempotencia. `T1ClientTripSync` marca enviado solo después de recibir **SERVIDOR OK** y reintenta si no hay conectividad, QR o si hay otro informe en cola. La sincronización periódica de muestras de telemetría (~1 minuto) se mantiene y la grabadora pide también un envío final.
4. **Backfill:** los clientes ya terminados antes de instalar la actualización se convierten **una sola vez** desde `client_trips.csv` a informes `CLIENT_FINISHED_V1`, **sin etiquetas**, con kilómetros eléctricos/desglose 1035 vacíos cuando no existía ese registro. Se prioriza enviar clientes nuevos antes que el histórico. Los CSV originales nunca se borran.
5. **Distancia estimada:** observación comprobada de **22,9 km OEM contra 24,55 km integrados por DriveLab**, razón `22.9/24.55 ≈ 0.93279`. Se aplicó esta **calibración provisional únicamente sobre nuevos incrementos desde velocidad OEM** (`speed_2148 * dt / 3600000 * 0.93279`). No aplica a GPS si algún día llega a usarse, ni reescribe viajes históricos. La señal original de velocidad se conserva en CSV. Debe validarse contra más trayectos reales; se indica ajuste provisional en interfaz y fuente del viaje.

## Limites y pruebas físicas pendientes
- RPM 1035 ya estaba siendo leída y validada para calcular `motorOn` 0/1/-1. Si la lectura falta, **no se contabiliza como eléctrico**.
- La clasificación de kilómetros se realiza con la última lectura de estado 1035 de cada intervalo de 3 segundos; los cambios dentro de un intervalo son aproximados.
- Un kilometraje de viaje ya iniciado antes de actualizar conserva la parte acumulada sin recalibrar; no se mezcla retroactivamente ni se altera el historial.
- La clasificación 1035 solo registra kilómetros acumulados desde esta versión; en clientes antiguos el valor no es reconstruible si no se guardó el estado OEM.
- El recibo **SERVIDOR OK** requiere confirmación real de la Edge Function y vinculación QR. Sin internet, o si otra subida está activa, el resumen queda en archivo privado y se reintenta. El usuario ve el estado en la primera pantalla.
- El desglose eléctrico es **kilómetros con el térmico apagado**, no consumo de energía en kWh, y no implica motor eléctrico 100 % del tiempo si el vehículo se mueve por inercia.
- Precio y litros calculados continúan etiquetados experimentales. No se alteraron los controles OEM EV/HEV, otros diagnósticos, recirculación ni la firma del Receiver.

## Instalación
Instalar **Receiver 0.2.49 / code 50** sobre Receiver 0.2.48 o anterior sin desinstalar ni borrar datos. Sender **0.2.16** permanece igual.

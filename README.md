# ARCHIVADO LÓGICAMENTE — DriveLab Auto Standalone

**Circuito de compilación y OTA desactivado el 23/11/2026.**

El único repositorio de código y compilación DriveLab es
[bruceferra/drivelab](https://github.com/bruceferra/drivelab).

- No se realizan nuevas compilaciones, firmas ni publicaciones desde este repositorio.
- Se retiraron todos los workflows antiguos de GitHub Actions para impedir ejecuciones accidentales.
- Las antiguas releases siguen disponibles temporalmente como respaldo técnico; **no son el destino OTA definitivo**.
- El usuario autorizó reinstalar las APK DriveLab desde cero, sin migrar bases ni configuraciones locales.
- Los nuevos APK se compilarán en Windows propio y obtendrán actualizaciones SOLO desde DriveLab Cloud.
- El borrado del repositorio completo requiere usar Settings > Danger Zone de GitHub cuando el nuevo circuito esté verificado.

Este README es una señal de retiro, **no** una afirmación de que DriveLab Cloud ya esté desplegado.
